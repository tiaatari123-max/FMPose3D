Running Kinematics Research

Project Overview

This project uses FMPose3D to estimate 3D human pose coordinates from running video.

Research Workflow

Process running video using FMPose3D.

Extract predicted 3D joint coordinates.

Export frame-by-frame coordinates to CSV.

Inspect and validate the predicted joint positions.

Prepare the data for further running biomechanics analysis.

Current Dataset

Video: Running video

Frames: 266

Frame rate: Approximately 29.89 FPS

Output: Frame-by-frame 3D pose coordinates

Notes

Joint labels and coordinate conventions must be verified against the model before quantitative biomechanical interpretation.
